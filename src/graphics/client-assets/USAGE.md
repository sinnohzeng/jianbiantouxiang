# 东黎羊绒品牌 LOGO 使用说明

## 1. 品牌色（全部透明背景）

1. 主色深咖 `#231916`：浅底首选，体现羊绒品牌暖调。
2. 黑色 `#000000`：仅用于纯黑白印刷。
3. 白色 `#FFFFFF`：深色底反白。

品牌只有这三个颜色版本，没有金色、绿色或其他多色 LOGO。

## 2. 六种图形结构

1. `symbol` 图形标：单山羊，用于头像、网站图标、小尺寸落款。
2. `wordmark-cn` 中文字标：「東黎」。
3. `wordmark-en` 英文字标：DONGLI。
4. `lockup-full` 完整组合：山羊 + DONGLI + 東黎，用于封面、主视觉。
5. `wordmark-bilingual-stacked` 双语堆叠：英文在上、中文在下，用于方形或竖版空间。
6. `wordmark-bilingual-inline` 双语横排：英文与中文左右排列，用于页眉、页脚等长条空间。

## 3. 怎么选文件

1. 先按底色选颜色：白、米白、浅金等浅底用主色深咖；深绿、深咖、照片等深底用白色反白；纯黑白印刷用黑色。
2. 再按版面选结构：主视觉用完整组合，横条用双语横排或英文字标，方形版面用双语堆叠，小尺寸用图形标。
3. 优先用 SVG：可置入 PPT、Figma、Photoshop、网页与印刷文件，任意缩放不模糊；不支持 SVG 的场景再用同名 PNG。
4. 前端开发用 `04-自适应单色` 目录下的 `-mono.svg`：填充为 `currentColor`，颜色随页面 CSS 自动适配明底、暗底与交互态，一个文件即可，无需维护多份。
5. 金色质感的正确做法：金底上叠白色反白版，米金浅底上叠主色深咖版；不存在金色 LOGO 文件，确需金色版本时从 AI 母版重新着色派生。

## 4. 安全空间与禁用项

1. 每个文件四周已内置等比留白（主体长边的 9%），排版时不要裁切到图形边缘，其他元素不要压进留白区。
2. 等比缩放，禁止拉伸、压扁、斜切、旋转。
3. 只允许使用第 1 节三个品牌纯色，禁止自行改色、加渐变、描边、阴影或其他特效。
4. 不要给透明底 LOGO 自行垫色块；换底色时直接选用对应颜色版本。

## 5. 文件命名规则

文件名格式为 `dongli-{结构}-{颜色}.png` 或 `.svg`，结构与颜色的英文标识见第 1、2 节；以 `-mono.svg` 结尾的是 `currentColor` 自适应单色版。

## 6. 源文件

`03-源文件/东黎-logo.ai` 是客户原始矢量母版，含五个画板、文字已转曲。新增着色或结构变体一律从该母版派生，并在品牌资产仓库留档；日常使用请取成品目录中的文件，不要直接使用画板原始渲染。
