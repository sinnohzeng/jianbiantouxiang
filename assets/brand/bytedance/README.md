# 字节品牌 Logo 精选

本目录收录用户指定用于渐变头像的 25 份 SVG/PNG。manifest.json 记录源文件 SHA-256；生成器将简单 SVG 样式转为绘制属性。商标与素材权利归各品牌所有，项目 MIT 许可不授予品牌使用或再分发权。

- 豆包工作：2026-11-12 换为人物形象版。独立图标来自主体形象.png（554×554），黑字、白字组合来自品牌标识黑字.png、品牌标识白字.png（2012×554），均保持原始像素。
- 飞书：独立原色图形由原色中文SVG组合的第二个g组提取，路径及颜色不变，viewBox为0 0 90 100，保留原100单位纵向画布及15单位上下留白；原色、纯黑、纯白中文组合保持原稿。
- 豆包：原色人物与中文组合，没有伪造纯黑白人物稿。
- 火山引擎、抖音集团：原色组合。
- 巨量引擎、CapCut：黑、白组合。
- 字节跳动、抖音、西瓜视频：原色、纯白组合。
- 今日头条：原色、纯黑、纯白组合。
- TikTok：第三方Simple Icons形状的黑白音符，非官方原始文件；已有图标保留。

版本保持原始比例、颜色、透明度，选择后不再进行程序染色。未提供的版本不补造；彩色图形加黑字仍属于原色组合，不标作“纯黑”。国内剪映AI母版不能当作CapCut英文标识，当前仅收可直接使用的CapCut SVG。

豆包工作独立图标、黑字组合、白字组合与飞书独立图形的稳定ID分别为doubao-work、bd-doubao-work-black、bd-doubao-work-white和lark，资源名为doubao-work-avatar、bd-doubao-work-avatar-black、bd-doubao-work-avatar-white和feishu-symbol-202611。包内未附具体安全距离数值，不能把透明边界等同品牌安全规范；本目录保留源图形已有空间，排版按可见像素的外接框计算尺寸，外围留白由布局提供。
