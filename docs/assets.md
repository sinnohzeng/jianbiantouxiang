# 素材来源与权利

项目代码采用 [MIT](../LICENSE)。字体、图标、商标和客户稿件分别遵循其许可与品牌要求；素材公开可下载，不能据此推定有任意使用或再分发权。

| 素材 | 来源与说明 |
| --- | --- |
| 渐变着色器 | [Paper Design Shaders](https://github.com/paper-design/shaders)，Apache-2.0 |
| 内置线性图标 | [Lucide](https://github.com/lucide-icons/lucide)，ISC；版本以 package-lock.json 为准 |
| emoji 索引 | [emojibase](https://github.com/milesj/emojibase)，MIT |
| emoji 图形 | [Noto Emoji](https://github.com/googlefonts/noto-emoji)，Apache-2.0 |
| 默认字体 | Noto Serif SC、Noto Sans SC，OFL；[宋体许可](../public/FONT-NOTO-SERIF-SC-LICENSE.txt)、[黑体许可](../public/fonts/OFL-NotoSansSC.txt) |
| 第三方品牌库 | [dashboard-icons](https://github.com/homarr-labs/dashboard-icons)，仓库 Apache-2.0；品牌权利仍归各所有者 |
| 客户品牌 | 用户提供的 HARMAY、东黎稿件；[来源](../src/graphics/client-assets/README.md)与[使用要求](../src/graphics/client-assets/USAGE.md) |
| 字节品牌 | 用户指定素材，文件与哈希见[目录说明](../assets/brand/bytedance/README.md)及 manifest.json |
| ISV 品牌 | 用户收集素材，版本缺口见[目录说明](../assets/brand/isv/README.md)及 manifest.json |

其他品牌的来源逐项记录在 [scripts/brand-list.json](../scripts/brand-list.json)。Qoder 为参照标识描摹的矢量，不能标为官方原文件。来源证据与使用授权应分别核查。

品牌图形保持比例和规定颜色；东黎素材保留其内置留白。程序染色仅适用于明确提供该选项的历史条目，不能自动补出所谓官方黑白版本。客户原始素材包及内部说明保持私有。

界面使用 shadcn/ui、shadcnblocks 和 React Bits 的组件。付费 registry 的访问与再分发按对应服务条款处理，仓库中的代码许可不代替上游许可。

早期渐变方法参考 [Justin Jay Wang](https://justinjay.wang/methods-for-random-gradients/)。
