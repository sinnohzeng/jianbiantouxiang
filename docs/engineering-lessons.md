# 工程经验

本页保留修改代码时最容易再次踩到的问题。各轮过程与更多案例见[v8.9 经验记录](archive/v8.9/engineering-lessons.md)和[验收记录](audits/)。

## 默认值会改变的不只是初始画面

先列出读取默认配置的入口：首次进入、重置、残缺存档、客户预设、CLI/MCP、样张。更新默认效果时也检查布局分支；投影若被自动放大条件排除，会同时改变字号和间距。用纯色/投影的布局等价测试与实际图片共同验证。

旧存档没有“用户主动选择”的标记时，不能把等于旧默认的值当成未设置。保留所有显式值，只为缺失字段补新默认。客户预设应仅设置自身需要的字段，避免选择 Logo 时顺带覆盖文字效果。

## 先量实际像素，再判断视觉

透明画布、字体框和可见墨迹框不同。用 alpha 边界检查素材，按 TextMetrics 测量文字；品牌要求的留白另行保留。字体栅格化不是严格线性缩放，每个候选字号须重新量测。

无越界、边距相等或质心归中都不足以证明好看。保留用户参照，对照完整图和小尺寸圆裁；宽字标和细衬线的可读性不能靠平移解决。默认效果调整后看深浅底、两行、Logo 和无 Logo。

## 验证当前产物

Playwright preview 服务的是 dist，不是正在编辑的源码。先构建，再确认预览服务来源；测试启动后不要继续改源码。截图要等待真实加载遮罩退出，不能吞掉等待超时再把遮罩截图算作通过。

限制浏览器并发，避免软件渲染争抢资源制造超时；失败时检查具体断言和截图，不先扩大时间预算。图片选择器可能提前加载选项素材，网络监听须在触发加载之前注册，不能假定选择时还会再发请求。截过图不等于看过图，交付只报告实际查看的范围。

## 异步结果须绑定配置

编辑时立即撤下旧长按图，最新编码完成后再显示。导出记录开始时的配置，历史缩略图按哈希回填。保存配置与图片来自不同时间点，会造成恢复后的内容与缩略图不一致。

剪贴板的 ClipboardItem 应在用户手势内创建，把后续编码 Promise 交给浏览器。编码完成后检查真实 Blob MIME，再决定扩展名和体积处理。

## 素材更新涉及三个入口

预览、选择器和导出必须使用同一资源映射。稳定配置 ID 可保留，文件 URL 应随素材更新。历史缩略图是缓存，失效时保留配置和无关历史。

SVG 的 viewBox 不总能提供可用于扫描的固有像素尺寸；缺尺寸时从 viewBox 等比推导。上游依赖 style 或内部 use 的文件需在生成期规范化，运行时仍走白名单。新品牌库必须全量解码出图，存在文件不等于能正确绘制。

## 文档以实际命令为准

文档先确定读者任务，再分配事实；当前说明只写可用行为，历史过程放归档。命令逐条对照脚本和文件，特别检查示例路径、运行目录、安装步骤与输出覆盖规则。

容器运行目录只保留复制进去的模块。构建成功不保证 Node 入口的相对导入完整；需在与运行目录相同的文件结构中检查启动链，再在目标容器验证沙箱。

## 分支清理要可逆

提交 SHA 不同也可能补丁等价，可用 git cherry 核对。独有提交逐项拆分：保留有效功能，过时的版本号和默认值不带回现状。删除前建立可恢复的远程标签，并再次确认分支尖端未变化。
