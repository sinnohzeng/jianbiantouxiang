# 制作头像

打开 [渐变头像](https://jianbiantouxiang.com)，输入两行文字，选择 Logo 和背景后导出。第二行可以留空。首次进入及恢复默认显示「工作新习惯 / 你说豆包干」和豆包工作图标；已有存档优先恢复。

## 调整文字与 Logo

字号默认自动计算。两行纯文字采用同级字号；带 Logo 时突出第一行，第二行作说明。主行默认宋体、副行黑体，均带强度 40% 的投影。浅背景仍需选择有足够对比的文字色，投影只辅助边缘辨认。

- 内容、字号和上下位置在每行旁边。手机可点加减或输入数值，桌面也可拖滑块。
- 字体、字重、文字色、投影等效果在「字体与样式」中。选择「纯色」可关闭投影。
- Logo 大小和上下位置在图标节中；左右位置按需展开。
- 「恢复自动排版」恢复字号和位置计算，保留文字、字体、图标与配色。
- 顶栏设置中的「恢复默认」重置整份头像配置，执行前会确认。

旧存档中明确保存的效果、强度和字体继续保留；缺失字段采用当前默认。因此升级后已有纯色头像不会自动变成投影。

图标库可选客户品牌、字节品牌、ISV 品牌、内置图标和 emoji，也可上传 SVG、PNG、WebP。品牌颜色应选对应素材版本；部分历史图标的「程序染色」会损失细节，不能当作官方单色稿。上传图形和字体在刷新后需重新上传。

## 选择背景

四种质感为柔光、流动、丝绸、颗粒。可以选择内置配色，自定义 2–6 个颜色，或用种子色生成一组。

「变换底纹」只改变背景种子；「随机配色」只换配色。两者均保留文字和 Logo。

## 检查聊天列表效果

在设置中开启安全区或网格参考线，检查主体是否靠近边缘。参考线只在预览出现。圆形安全区是本项目的排版约束，不是飞书官方规范。

「内容超出安全区」表示最终文字或 Logo 边界越界；「48 像素小头像中文字偏小」是另一项可读性提示。遇到小字，优先缩短文字或删去副行，再看 32、48、64 像素实际小图。完整品牌字标过宽时，即使没有越界也可能难以辨认。

## 导出与恢复

点击「导出」直接下载；右侧导出选项可选尺寸、形状、JPG/PNG/WebP 及复制图片。网页支持 64–8192 像素，原生渲染上限由设备决定。PNG 为无损格式，文件大小无法保证；WebP 取决于浏览器编码支持。微信内置浏览器按提示长按保存。

配置自动保存在当前浏览器，历史保留最近 8 次导出结果。浏览器清理数据或禁用存储可能使存档丢失。看到版本更新提示时，点击「刷新」会先保存当前配置再载入新版。
