# 原始参照和反证

用户手调截图包含 HARMAY Logo＋“飞书对接 / 外部群”和东黎图形＋“飞书对接”；未找到东黎两行手调稿。截图低分辨率且有水印，不可准确逆推出字体、字号与像素指标。目视可确认 HARMAY 副行明显弱于主行，东黎图形与单行作为一组。[^user]

v8.2.1 以包围盒上下留白近似相等支持改善判断，仍被用户否定。80% 副行过重，加大的图文间距让三层拉散；东黎透明品牌留白参与框架居中，实际墨迹偏下。旧光学位移被圆边钳住，部分实例结果为零。[^prior] 这证明无裁切与框架等距不足以验收视觉位置。

# 有限修正

带 Logo 的副行改为主行 62%，纯文字与手动字号保持。宽字标间距目标 6% 短边，其他图形 4.5%；两行取 3.5% 短边与 0.18em 较大值。先按现有几何求解，再用实际掩膜边界中心与墨迹分量中心的 75:25 混合提出整组纵移；最多 3.5% 短边。质心不是视觉真值，比例是本轮候选设计，不是科学验证或品牌规范。[^optical]

若圆裁阻挡位移，允许图文统一微缩，最多 6%；仍放不下则减小位移。品牌透明留白及比例一并保留，显式手动位置不被覆盖。没有新增品牌特例和逐字位移规则。

# 视觉判断和限制

相对上一版，副行回到辅助层级，东黎图形/横版的下坠感减弱，HARMAY 主行与副行的关系更接近手调参照；这是模型逐张看图后的判断，不是用户认可。完整东黎的组合仍复杂，小尺寸优先用图形标；32 px 的细字不保证逐字可读。没有真实飞书客户端新上传验证，也没有独立人工评审或公开视觉实验。最终是否符合用户审美仍待其判断，不再自称全自动达到某个分数。
