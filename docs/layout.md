# 排版参考

本页供修改排版代码时查阅。用户操作见[使用指南](usage.md)，原始对照与测量见[验收记录](audits/)。

## 自动布局

图文顺序为可选 Logo、第一行、第二行。网页通过真实字体 TextMetrics 求解字号，默认按圆形安全区检验，输出形状另由画布设置决定。默认安全边距为短边 3%；这是产品参数，不是聊天平台规范。

纯文字自动双行同字号；带 Logo 时副行目标为主行的 0.62。主行手动而副行跟随时也用 0.62。每行可以单独指定字号与位移，手动位置优先，越界时提示，不暗中改值。

整组先建立至少 6% 边距的基准布局，再做光学校正和最多 16% 的等比放大，受实际圆裁边界限制。仅在自动字号、零手动位移、纯色或投影效果时启用此步骤；纯 Logo 按用户安全区直接计算。投影沿用纯色的布局，模糊尾部不作为字形墨迹框；贴边或大强度效果仍需查看实际圆裁图。

## 图形与间距

网页 Logo 大小范围为 10%–80%，默认 52%。带文字时，基准高度取安全框高的 52% 除以宽高比平方根（宽高比至少按 1 计），再受基准宽度约束；最终按用户大小线性缩放。宽 Logo 采用近似等面积尺寸，过宽时由圆裁求解协调文字大小。纯 Logo 在安全圆内取最大同比例矩形，再按大小参数缩放。

宽字标到主行的目标间距为短边 6%，其他图形为 4.5%。有 Logo 时主副行间距取短边 3.5% 与主字号 18% 的较大值；纯文字取较大字号的 18%。行高相对默认 1.03 的差值按较大字号加减间距，最小为 0。算法集中在 `src/text/spacing.ts`。

图形测量保留比例。一般素材去透明外边，东黎保留品牌要求的留白。源图透明边界与品牌安全距离不是同一概念。

## 光学与几何

整行水平补偿最多 0.02em，不逐字移动。掩膜质心只是诊断代理。整组纵向按文字与 Logo 的可见边界居中，Logo 组位移最多短边 3.5%，圆裁需要时最多缩小 6%；每个候选字号重新量测，避免把栅格字体当作线性缩放。

纯文字两行以可见边界居中，不按质心整体上移。手动位移保留。安全区提示根据最终各行与图形边界计算，与预览参考线共用几何条件。

## 字体与效果

默认主行为 Noto Serif SC 700、副行为 Noto Sans SC 700。缺失字体字段补默认，副行显式 null 表示跟随。字号、量测和绘制使用同一字体字符串，并等待字形分片加载完成。

默认文字投影强度为 0.4。现有绘制公式在该强度下使用 0.33 alpha、字号 6.4% 的模糊和字号 2% 的下移；浅字配黑影，深字配白色漫射。两行各按自身字号计算。品牌原稿保持源色与原形；网页 UI 文案不使用这份头像配置。

投影不能保证任意背景对比度。检查应包括完整图、32/48/64 px 圆裁和真实客户端；48 px 时字形高度低于 6 px 的提示是产品阈值，不是可读性认证。

## 修改后的检查

运行 `npm run ci`；布局改动先启动 `npm run dev`，再运行 `node scripts/audit-geometry.mjs /tmp/avatar-geometry-audit` 取得实际像素报告。保留旧版与新版实际图像，比较字形边界、圆裁、层级和小图辨认，而不是只看无溢出。

CLI/MCP 复用绘制、光学和圆裁模块，但使用独立的单行输入和 Logo 处理；参数范围以[自动化指南](automation.md)为准。
