## 默认效果

首次与重置使用投影 0.4；缺字段补默认，显式 plain、零强度和其他效果保留。客户预设原先写死 plain，现只修改其必要字段，保留现有文字效果。投影与纯色进入同一自动放大路径，避免只改效果却改变布局。

实际调用网页合成管线生成四组 512 px 配对图片：深底 Logo、浅底 Logo、晴空白字、浅底深字。四组字号与坐标完全相同，像素差分别为 23164、26721、32232、29532，确认效果真正进入输出。查看完整图与 32/48/64 px 圆裁，浅底白字轮廓有所改善，深底变化较小。投影不保证任意颜色或小字都足够清晰。

证据：[对照拼图](../assets/reviews/v8.10.0/shadow-review.png)、[测量数据](../assets/reviews/v8.10.0/shadow-metrics.json)。同目录保留八张原图。

## 验证结果

- `npm run check` 通过：lint、格式、类型检查、77 文件 / 911 项单元测试、网页构建、3 项服务单元测试与服务构建。
- 服务集成 7 项通过，覆盖实际渲染、CLI、官方 SDK 的 HTTP/stdio MCP、批量、资源限制及恶意 SVG。云环境不支持 Chromium 沙箱，首次启动因此失败；受控测试改用 `AVATAR_CHROMIUM_SANDBOX=0`，产品默认保持启用沙箱。
- 浏览器全量 85 项首轮为 83 通过、2 失败。两项均为 ISV 选择器提前加载图片，测试在加载后才监听响应；网络记录确认原图返回 200。监听移到打开选择器前后，桌面和手机两项复验均通过，没有提高超时或修改产品行为。最终 lint、格式与类型检查再次通过。
- 文档中的 options、validate、单张和三项 batch 示例实际执行成功；[CLI 图片](../assets/reviews/v8.10.0/cli.png)已查看。

浏览器检查使用 Chromium 的桌面与手机视口模拟，不等同于真机 Safari 或飞书客户端验收。完整 Docker 构建和目标环境沙箱未验证，本轮未部署远程 MCP。

四张标准样张已重建并逐张查看，覆盖 48 组配色、四种质感和文字效果。浅底颗粒高亮区域的白字仍需结合文字色选择，不能用投影替代对比度。

云端高分辨率软件渲染截图出现默认黑体的 4 秒加载回退提示；串行也可出现。独立普通视口冷启动中两份默认字体 CSS 返回 200，实际 Sans 字形均为 loaded。字体加载策略不在本轮变更范围，此结果不能当作真机加载失败或字体文件缺失的证据，亦不能宣称所有冷启动均无提示。

16 张桌面、iPhone 15 与 SE 模拟截图已逐张查看，包含深浅主题和导出面板，保留于 [UI 证据目录](../assets/reviews/v8.10.0/ui/)。桌面浅色首张在文字层完成前截取，补拍以实际文字层 alpha 非零为条件；[完成后的画面](../assets/reviews/v8.10.0/ui/desktop-light-ready.png)保留完整图文。手机画面和导出面板未见本轮新增的遮挡或溢出。
