## 流程覆盖

| 流程 | 验证方式与边界 |
| --- | --- |
| 文字输入、大小/上下微调、自动恢复、字体选择 | 既有桌面/手机 E2E 与组件用例；不改变已认可头像布局 |
| 品牌/内置/emoji 选择、颜色版本、移除、上传 | 既有 E2E；非法 SVG 实际错误提示；本轮渐变像素与索引网络故障复现 |
| 配色、种子、质感及参数 | 既有 E2E、纯逻辑回归及各视口检查 |
| 撤销/重做、重置、历史恢复 | 既有 store/E2E；文本框保留浏览器原生撤销；异步历史增加快照检查 |
| 导出、复制、格式、画布、微信图片 | 既有 E2E + 微信新增用例；toBlob=null 注入后错误提示和按钮恢复 |
| 顶栏设置、主题、语言、简介、新版本 | 既有 E2E 与 SW 单测；简介新标签保留状态；更新前同步 |
| 手机滚动、桌面列布局、弹层 | 320/390/768/1024/1440/1920 px 浏览器视口；Tab 中心命中、横向溢出和截图 |
| Web/CLI/MCP、资源与路径 | 既有 HTTP 单测及 CLI/stdio/HTTP 官方 SDK 集成；继续使用声明协议，不改变服务部署 |
| 网络与隐私 | 默认字体本站加载；上传字体替换合成路径实际请求没有测试文字。其他字体加载器不传正文 text 参数，字体名子集传目录显示名。未将此有限采样宣称全网络匿名 |

## 实际像素证据

100×100 线性红蓝 SVG，经同一清洗器及真实 Image/Canvas 渲染，(10,50) RGBA=(228,0,26,255)，(90,50)=(24,0,230,255)，证明渐变定义参与绘制。同名 `same.woff2` 先注册 Noto Serif SC 再注册 Noto Sans SC，配置字体身份保持，实时文字画布像素发生变化；不是只检查通知计数。

## 架构及安全边界

网页配置与会话素材继续本地管理；独立服务仍由隔离 Chromium context、有界队列和超时执行，HTTP 身份/来源/请求尺寸检查保持。远程输入为内联字节，CLI 本地文件是显式路径，输出独占创建。未发现需要数据库、额外服务或协议迁移的证据。

SVG 只保留既有白名单元素/属性及内部引用；保留 stop 不放开脚本、外链或 HTML。上传像素检查在 Image 加载之后、透明扫描之前，浏览器最初解码成本仍可能较高。当前云环境 Chromium 的 SUID sandbox helper 配置不满足沙箱启动条件；固定测试夹具以本地测试模式执行，未改变生产默认沙箱选项，也未部署远程服务。存储可能因配额、权限或清理失效；离页同步不保证进程强杀保存。会话上传素材刷新后需要重传。

## 验证记录

lint、format:check、typecheck、build 通过；869 项单测（76 文件）、3 项 HTTP 单测、7 项 CLI/MCP 集成通过。浏览器完整首轮 60/61 通过，一条重置弹窗在 data-closed 状态等待动画结束超过 5 秒；最终构建定向复核该场景和 5 项新增/受影响流程，共 6/6 通过，未修改重置逻辑或放宽断言。新增索引网络恢复场景纳入 E2E；最终完整重跑 62/62 全部通过（12.7 分钟）。截图为 Chromium 模拟视口，微信为 UA 模拟。没有真人可用性实验、真实 iOS/Android 软键盘、辅助技术或飞书客户端验证，不宣称 WCAG 全站认证。主观头像审美仍以用户已认可版本为基线。
