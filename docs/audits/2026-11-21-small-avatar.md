# 小头像检查验收

基线 69c6d1a / v8.13.2；本轮版本 v8.14.0。常驻小字劝删提示改为按需检查，默认字号、主副层级、字体和排版算法均未修改。

## 方法与边界

当前配置先按原画布尺寸经 createExportArtifact 合成并编码，再由浏览器以 32/48/64 CSS px 显示，并以 object-fit: cover、圆形遮罩模拟中心裁切；默认选择 48px。不会在小画布重新求解布局。屏幕密度决定物理像素数，明确标注模拟，不声称飞书客户端实测。

字形高度按所选尺寸折算，6px 只作风险筛查；只有检查窗口内出现主文字/副行说明，不用错误样式或阻止导出。原预览的越界警告保留，检查中也显示原布局的越界结果；对于手动或非方形内容，中心圆裁的实际效果以小图为准，不承诺所有构图都不会裁掉内容。
