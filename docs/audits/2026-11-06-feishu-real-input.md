## 输入与证据范围

用户提供了旧 HARMAY、东黎羊绒圆形头像截图和飞书原生“北区 / 连接器”截图。截图的 JPEG 像素测量是近似值（约 ±2 px），已避开水印和外圆描边；不是品牌原文件，也不是新版的飞书客户端验收。

HARMAY 当前首页 `https://www.harmay.com/zh` 使用 PNG：`https://mp-digital-cdn.harmay.com/storage/00ec7a02560449b4a605435c6958b6f5.png`。下载文件魔数确认 PNG，184×75；CDN Content-Type 错标为 image/jpeg。SHA-256 为 `aae2463d96d4c457d75b69dda86a056cc77663941fa1221b40e98ff3b00b6bbc`。

官网 JS `/_next/static/chunks/3risl0s_ic8l7.js` 的导航字标组件明确引用备用 `https://www.harmay.com/media/harmay-logo.svg`；该 URL 返回 HTTP 200、image/svg+xml、2039 bytes，含六条 Illustrator 矢量路径，viewBox 727×87。SHA-256 为 `9183710845f646432b4b64a28601c119b67a96f8c5382a3372de6bfdc7ce7d32`。它是官方备用 SVG，不把它说成当前首页首选资源，也不把 PNG 描摹成矢量。

官网素材保留在独立测试目录，不作为默认品牌内置，也不随此开源提交分发。商标权与素材使用许可不属于本项目 MIT 许可；需要公开分发时另行确认范围。通用测试采用自造几何图形；`node scripts/review-logo.mjs <用户素材.png或.svg> <输出目录>` 可重复执行真实上传、合成与圆裁检查。

## 发现与修复

1. 8.1.0 的纯文字第二行仍固定为首行 62%，使“连接器”宽度只占圆直径约 62.5%，而参考图约 74.7%。无 Logo 自动双行现在采用相同字号，共同适配；保留有 Logo 的主副标题层级、显式手动字号和补偿。
2. 官网 PNG 实际可见区域为 183×19，位于 y=29；画布高 75。网页上传此前把透明上下留白计入布局，现以 alpha 边界确定尺寸，绘制仍使用原文件源矩形。黑白与低 alpha 笔画均保留，不猜测删除不透明底色。
3. 官网 SVG 的 evenodd 规则在简单类样式中。现在只支持有限绘制属性和简单类选择器，将它们转为安全属性后删除 style。URL、导入、复杂选择器、滤镜及脚本继续拒绝。
4. 官网 PNG 带压缩元数据。原先直接拒绝造成合法素材无法导入；现在剥离 iCCP/iTXt/zTXt，绝不解压元数据；动画 PNG 仍拒绝。返回元数据被移除提示，彩色原图的色彩管理可能受影响。
