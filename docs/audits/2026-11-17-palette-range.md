# 六组配色覆盖记录

状态：本地验收通过，尚未发布。

## 原始材料与选择

基线为 51 套。浅暖色已有珊瑚、桃粉、杏金，深暖色偏近黑余烬与古铜；本轮补充独立橙色的明暗层级，以及黄、黄绿、高彩度深莓红。

原始色值来自 [Radix light.ts](https://github.com/radix-ui/colors/blob/main/src/light.ts) 与 [dark.ts](https://github.com/radix-ui/colors/blob/main/src/dark.ts)，2026-11-17 读取。组合为本项目选色，推荐文字色沿用项目深浅字规则。

| 配色 | 源节点 | 推荐字色 | 最低节点对比 |
| --- | --- | --- | --- |
| 浅橙奶杏 | orange 3、4、6 | 深字 | 11.59:1 |
| 鲜橙活力 | orange 9、8、7 | 深字 | 6.20:1 |
| 深橙焙火 | light orange 12、dark orange 7、8 | 白字 | 5.27:1 |
| 柠檬明黄 | yellow 10、9、4 | 深字 | 13.60:1 |
| 青柠嫩芽 | lime 8、10、5 | 深字 | 7.86:1 |
| 莓红丝绒 | dark crimson 4、6、7 | 白字 | 7.96:1 |

[线性配色对照](../assets/palette-range/comparison.svg)展示原始色值及推荐字色；[节点记录](../assets/palette-range/nodes.json)含完整数据。

已逐张查看六组深浅字对照及每组 32/48/64 px 圆裁。浅橙偏奶油杏色、鲜橙饱满、深橙偏暖焙棕，明暗层级可辨；黄、黄绿、莓红补足色相。推荐字色清晰；非推荐字色对照明显较弱。32 px 双行中文字偏小，48 px 副行仍偏小，64 px 更易读；这是保留既有默认文字长度与布局的限制，未擅改默认值。

桌面 1440×900、手机 393×852：逐个点击六组，断言实际配置 ID、文字色保持 `#ffffff`、页面无横向溢出，并真实下载 12 个非空 JPG。查看全部桌面与手机截图；桌面新增末行可到达，手机固定预览与操作条之间能点选，面板内容可继续纵向滚动。网页保留原字色，因此浅色组在默认白字状态下不满足推荐字色对比；用户需自行选墨黑，未改变现行契约。

本地修复：服务 HTTP 集成测试的配色数量断言由 51 更新为 57；验收脚本改用内嵌图像的页面内容生成截图，避免系统浏览器阻止 `file://`，并增加逐次 shader fallback 检测。
