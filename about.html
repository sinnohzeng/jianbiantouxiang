渐变头像

输入几个字，浏览器当场算出一张柔光质感的渐变图，导出就能当头像用。

版本 - MIT 开源

这是什么

一个做头像的小工具。填一到两行字，挑一套配色和一种质感，右边实时出图，点导出就下载。 图是在你自己的浏览器里算出来的，没有账号，不上传，也没有一行埋点。

起因是公司群里几十号人挂着默认灰头像，部门想要个统一标识，又不值得为这点事排一次设计。 缺的是一个十秒钟能出一张不难看的图的东西。

怎么用

  1. 1 打开就是工作台。左边两列填字与挑配色，右边是画框，改什么都当场看得见。
  2. 2 不知道要什么样的，就连点几下随机，看到顺眼的停下来。
  3. 3 点导出直接下载。手机上长按预览图就能存进相册，不用先点导出。

技术实现

渲染

四种质感是 WebGL2 片元着色器实时算的，不是叠现成的图。同一份配置在同一台设备上每次输出一致， 换一个种子就是一张新图。没有 WebGL2 的浏览器回落到 2D 近似渐变，导出拿到的也是这一张。

排版

字号是解出来的，不是拍脑袋定的。二分搜索能把两行塞进安全框的最大字号，中文逐字换行、 拉丁按词换行。给某一行加水平补偿只挪那一行，其余行的字号与坐标一个像素都不动。

字体

Google Fonts 全库按需加载，中文按 unicode-range 切片，Noto Sans SC 整包 1.1 MB， 实际只下载用到的那几十 KB。也可以直接上传本地的 TTF、OTF、WOFF、WOFF2。

图标

lucide 精选进首屏、全库懒加载，emoji 跨平台取同一份 Noto SVG，另有 58 个品牌标志。 上传的 SVG 按白名单重建，未知元素整支丢弃，不做黑名单修补。

导出

离屏合成走与预览同一套参数，JPEG 质量二分压到选定的体积档以内。预览与导出是两条独立路径， 共用引擎、文字、图标三个模块，所以调一个参数只落在一处。

界面

桌面上挑选栏拆不拆两列，判据是还剩多少宽度给画框，不是照着视口宽度写死断点。 底部操作条按自己有多宽换长短文案，因为它的宽度随微调面板开合在几百像素之间跳。

隐私

没有后端，没有数据库，没有埋点，也没有 cookie。所有配置存在你浏览器的 localStorage 里， 清掉浏览器数据就没了。上传的字体与 SVG 只在当前这次会话里有效，关掉页面就不在了。 装成 PWA 之后断网也能用；部署了新版本，开着的标签页会自己发现并提示刷新。

English

Gradient Avatar turns a line or two of text into a soft-light gradient image you can use as a chat avatar, profile mark or team badge. Four shader textures run on WebGL2, the font size is solved by binary search rather than guessed, Google Fonts are sliced by unicode-range, and the export path binary-searches JPEG quality to hit a size target. Everything runs in your browser: no account, no upload, no analytics. Source is on GitHub under the MIT license.
