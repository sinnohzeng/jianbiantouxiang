# 七客户素材精选入库

状态：已封存。日期：2026-11-20。

## 目标与边界

将用户明确授权的七客户 LOGO 包中的新增形态接入既有客户品牌选择器。新增润晖投资、行知探索、博润阳光、国养爱连、深纳普思五个品牌，补齐东黎的中文、英文及双语堆叠字标。话梅及东黎既有三种形态去重；不默认纳入博润旧火焰标，不公开母版、整包和内部资料。

每个新增形态使用包内彩色、黑、白成品，保持原形、透明度与比例；东黎优先 SVG 且保留安全留白。低分辨率 PNG 不重绘、不伪称高清矢量，寻找可验证来源；无法找到更清晰的同款时记录限制。可疑归属单列，不用相似品牌代替。

既有客户顺序及字节、ISV 等分组相对顺序不变；新形态接在既有客户后。沿用客户三态切换，默认品牌与文字排版不变。CLI 已有四个客户预设不擅自扩展契约。

## 验收

检查 ZIP 路径、文件类型与实际图像；来源及哈希可追踪。生成器输出、唯一 ID、三态资源、旧条目顺序、精确原稿与 SVG 安全检查。实际选择、预览、导出覆盖全部新增形态与三态；低分辨率标识检查 2048 导出与小头像。完整 CI；直接 main 推送、注解标签、公开资源与在线选择核验。

## 实到范围

五新增客户 12 形态、东黎三种补充字标，共 45 份成品；话梅及东黎既有形态去重，博润旧火焰标搁置。三态沿用现有控件，既有默认与分组保留。完整 CI、45 份实际渲染、63 次桌面/手机导出及低分辨率专项检查通过。质量限制和证据见 [审计](../../docs/audits/2026-11-20-client-brands.md)，版本见 [CHANGELOG](../../CHANGELOG.md#8130--2026-11-20)。
