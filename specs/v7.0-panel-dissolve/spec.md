# 微调面板拆解、操作条三格与顶栏设置 v7.0 规约（造什么）

状态：已封存。与实到实现的差异见文末“实到范围”，现状以常驻文档与代码为准。

## 1. 目标

把独立的“微调”面板拆掉，数值滑杆按归属散进文字、图标、配色、质感四张卡片；操作条从五颗按钮收成三格；主题、参考层与恢复默认收进顶栏的设置菜单；顶栏去掉标语、加备案号；环境光动得看得见；修两处界面 bug；域名切到 `jianbiantouxiang.com`。

依据是 owner 的一句判断：绝大多数使用者不调参数，调的人也只调一两项。一个要先点开、再在最左边多开一列的面板，对前者是噪音，对后者是绕路。参数跟着它所修饰的东西走，找得到、看得懂，用完就收。

## 2. 用户故事

- 作为使用者，我在文字卡片里打完第一行，字号就在输入框正下方；改了文字样式，强度就在样式正下方。不需要知道“微调”是什么。
- 作为使用者，我选了图标之后，图标大小就在缩略图下面；想把图标挪一挪，展开“位置微调”拖水平与垂直两条。
- 作为使用者，操作条上只有三件事：换一版、随机配色、导出。每颗按钮的名字就是它改动的东西，不多不少。
- 作为使用者，主题、网格、安全区、恢复默认这些不常动的东西都在顶栏右上角的齿轮里。
- 作为使用者，滑杆右边的数字与滑杆右端齐平，预览画框底下没有一条被切出来的横线，背景的光在缓缓流动。
- 作为 owner，顶栏右侧按钮左边有一行浅色小字的备案号，手机上它在页面末尾。

## 3. 决策与理由

每条都先写反方最强的论证，再写为什么仍这样定。

### D1 位置微调用滑杆行，收在折叠组里

反方（方向键）：十字方向键语义直白，一次一格，目标尺寸容易做到 24 px 以上，Canva 触屏端就是这么做的；滑杆在 ±25% 的量程上拖不出 0.25% 的分辨率，六行滑杆在窄列里压抑。

定案：滑杆行。理由三条。第一，读得出当前值：方向键不显示偏了多少，回中只能靠猜，而滑杆行的数值框既显示又能敲，重置钮一下回中。第二，与全站同一控件语言：字号、边距、强度都是滑杆行，补偿另起一套控件会割裂。第三，WCAG 2.5.7 明写滑杆旁的数值输入构成拖动的可接受替代，方向键单独用反而要另配触屏方案。精度问题由数值框兜底；视觉权重问题由折叠解决：六条补偿全部收在各卡片的“位置微调”折叠组里，默认收起。

补偿字段：文字每行水平加垂直（`typography.lineOffsetsX` 已有，新增 `lineOffsetsY`），图标水平加垂直（`layout.graphicOffsetX` 已有，新增 `graphicOffsetY`）。量程与步进照抄水平：±25%，步进 0.25%，显示一位小数。垂直基准与水平同构：行补偿按画布高，图标补偿按安全框高。补偿是纯位移，不参与字号求解，不挤压文字可用区；越出安全区只反映在 `overflow` 上。旧存档没有新字段时补 0，画面与升级前一致。

### D2 操作条三格：换一版、随机配色、导出

反方（三个独立随机）：配色、质感、种子三个维度正交，三颗按钮最诚实；反方（保留“随机颜色和质感”）：一次重掷多个维度惊喜密度高，Coolors 的空格键就是这么成立的。

定案：两个随机加一个导出。“换一版”只换种子，是主按钮，占八成点击；“随机配色”只换配色，种子与质感不动。现状那颗“随机颜色和质感”其实连种子也换，名字与行为对不上，这是命名撒谎，必须改。质感只有四格且全部常显，随机四选一省不下一次点击，不给按钮。导出保持主按钮加导出选项齿轮的分裂按钮。桌面一行三列，手机三格加齿轮通栏，三格全是短文案，长短两版文案与容器查询一起删。

存储层 `randomizeAll` 改名 `randomizePalette`，只换配色；`nextPaletteId` 的同 tone 优先规则不动。

### D3 视图开关与偏好进顶栏齿轮

反方（就近）：网格与安全区参考线要边看边切，放在画布旁的操作条里光标少跑一趟；Figma 把参考线开关放在画布右上角的视图菜单。

定案：全部进顶栏的设置菜单，操作条的“更多”删掉。理由：参考线开关记在 localStorage，跨会话生效，性质是偏好不是动作；它们的切换频率极低，多跑一趟光标的代价可以忽略；一个功能面很窄的单画布工具，四条设置项拆两处，使用者记不住哪个在哪，Excalidraw 把主题、背景、清空画布全放一个菜单就是先例。菜单内容自上而下：主题三档单选、网格、安全区、恢复默认。原来独立的主题按钮并入，触发器换成齿轮。“复制图片”只保留导出抽屉里那一份。

### D4 顶栏

删标语。备案号 `京ICP备2026029073号-5` 链到 `https://beian.miit.gov.cn/`，放在右侧按钮组左邻，`11px`、`text-muted-foreground/70`，无下划线，悬停才有。手机顶栏放不下，改在挑选栏末尾居中一行，同一个 key。`about.html` 页脚同样加一条。

### D5 四张卡片的内容顺序

文字卡片自上而下：第一行输入、第一行字号（带“自动”钮）、第二行输入、第二行字号（两行都有内容才出现）、字体、字重、文字样式、强度（样式为 plain 时禁用）、胶囊三行（样式为 pill 时出现）、文字颜色一行、折叠组“版面”（边距、行高、字间距，默认收起）、折叠组“位置微调”（第 1 行水平、第 1 行垂直、第 2 行水平、第 2 行垂直，按行有无出现，默认收起）。

文字颜色收成一行：行内标签、五个预设（白、浅灰、中灰、墨黑、纯黑）、一个自定义色块。去掉 hex 文本框与米白、深灰两档。

图标卡片填充态：现有磁贴之后是“图标大小”一条常显滑杆，再是折叠组“位置微调”（水平、垂直，默认收起）。空态不加任何滑杆。

质感卡片：四格与描述之后是种子行，再是折叠组“参数”（当前质感的五个参数加光感，默认收起）。

配色卡片不动。折叠组一律用 `PanelSection`。Base UI 的 Collapsible 收起时整块卸载，展开那一帧滑杆量到的是真实宽度，早先“滑杆不能挂在 display:none 里”的坑不会复现。

### D6 环境光

极光着色器现在每秒只走屏宽的 0.8% 到 3.3%，四层共线没有视差，bloom 之后逐像素亮度变化率约 0.12/255 每帧，人眼当它是静态图。GPU 逐帧在算，算出来的差分被稀释掉了。

改法只动 uniform 取值，不动 dpr、帧循环与层数，GPU 成本不变：`speed` 0.42 提到 1.3；四层速度改成 0.36、-0.17、0.24、-0.09，两层取负号反向漂移换视差；`noiseScale` 2.6 提到 2.9；`movementX` -1.15、`movementY` -0.7，纵向占比降下来，避免与 `verticalFade` 耦合成整屏亮度泵动；一、三层强度各降一档补偿时域对比度。CSS 兜底 `ambient-drift` 周期 26 s 收到 16 s，峰值位移 6%、-7%，三团光晕的相位延迟改成 0、-5.5、-11 s。验收指标：相隔 1 s 两帧的平均像素差（无头 Chromium、swiftshader、1440×900），改前 1.86，改后至少翻倍。这个数与间隔近似线性，且屏幕大半被半透明卡片盖住，读数天花板不高，所以看倍数不看绝对值。`prefers-reduced-motion` 与页面不可见时停帧两道闸不动。

### D7 两处 bug

滑杆行：数值框右缘比滑杆右端缩进 26 px，原因是列序“标签 | 数值 | 重置占位”把 20 px 占位加 6 px 间距放在了最右。改成“标签 | 重置占位 | 数值”，占位列无条件渲染，没给默认值的行也留着，否则数值框会滑进窄列。

预览画框：`preview-pane` 的 `overflow-hidden` 把三层长投影与光晕在画框下方切成一条横线。桌面改 `overflow-visible`，横向溢出由外壳 `main` 的 `overflow-hidden` 兜住；手机保留裁切（它是 sticky 层），投影收成两层短的、光晕外扩收到区底以内。

### D8 域名与部署

线上域名改为 `jianbiantouxiang.com`，托管在阿里云 ESA Pages，构建配置在 `esa.jsonc`；旧域名留在 Cloudflare Pages 上做 301。README、AGENTS.md、`package.json` 的 `homepage`、`docs/architecture.md` 同步；接入步骤与核对命令在 `docs/deploy.md`。

## 4. 不做

- 不给质感加随机按钮，理由见 D2。
- 不做参考线开关的画布角落入口，理由见 D3。
- 不给数值框加方向键步进：滑杆滑块本身支持方向键，够用。
- 图标越出安全区不报 `overflow`，与现状水平补偿同口径。
- 不迁移 localStorage 里的 `gradient-avatar:inspector-open`，残留键自然失效。

## 5. 验收

- 闸门全绿：`npm run lint && npm run format:check && npm run typecheck && npm test && npm run build`，再 `npm run e2e`（桌面 1440×900 与 iPhone 15）与 `npm run screenshots`。
- 桌面 1440×900 首屏放得下四张卡片（折叠组收起态），主预览区不出现滚动条，画框仍落在预览区内。
- 顶栏：无标语；备案号可见、链到工信部；设置菜单里能切主题、切参考层、恢复默认。手机上顶栏无备案号，页面末尾有。
- 操作条：`shuffle-color`、`shuffle-palette`、`export-action`、`export-options` 各一，无 `more-menu`、无 `inspector-toggle`。点“随机配色”后存档里 `seed` 与 `style` 不变、`palette` 变了。
- 文字卡片：字号紧跟第一行输入之后，第二行字号紧跟第二行输入之后；“位置微调”展开后四条，拖“第 1 行垂直”后存档里 `lineOffsetsY[0]` 不为 0。
- 滑杆行：数值框是第一行最右一格，重置占位在它左边，没给默认值的行也有占位。
- 环境光动能指标不低于 5（见 D6）。
- i18n 五份字典与 `keys.md` 双向对齐，`tests/i18n` 绿。

## 实到范围

按规约做完，四处与文字有出入或规约没写到：

- 手机端备案号那一行自带操作条的底部让位内距，`sm:hidden` 之后 640 到 1023 这一档没人让位，`PickColumn` 外层补了 `sm:max-lg:` 一档的内距。
- 设置菜单里的主题三档用 `DropdownMenuRadioGroup`，勾选态就是当前主题；顶栏触发器只剩齿轮，不再显示当前主题图标。品牌那一格加了 `flex-1`，手机上备案号隐藏时按钮组仍靠右缘。
- 桌面首屏实测（1440×900）：四张卡片底边 694、798、569、801，两条挑选列溢出 0，画框 490 px，折叠组收起态放得下，未调卡片内距。
- 环境光第一版按 `speed` 1.0 实测 1 s 像素差 2.5 到 3.6，只到改前的 1.4 到 1.9 倍，`speed` 再提到 1.3，其余取值不动，实测 4.1（改前的 2.2 倍，多次实测 3.0 到 4.1）。
