# 直接导出与行级排版 v3.1.1 规约（造什么）

状态：已落地，2026-08-29。本版是 v3.1 的可用性增量，不改变 v3.2 图标徽章的方向。

## 1. 用户故事

1. 用户打开首页，默认看到方形画布，两行“飞书 / 效率先锋”，第一行明显更大，导出可直接设为头像。
2. 用户点击主操作“导出”，浏览器立即下载 JPG，不需要先打开抽屉再点一次。
3. 用户想粘贴到聊天窗口，点“复制图片”；想保留文件，点“下载”。两个动作都是显式按钮。
4. 设计同事觉得第二行偏小或偏左，在文字面板分别调这一行的字号比例与水平视觉补偿。

## 2. 功能规约

### 2.1 默认值

- 默认画布 `shape: square`，尺寸仍为 1024×1024。
- 默认文字为显式两行：`飞书\n效率先锋`。
- 默认行级字号比例为 `[1, 0.62]`，保证“飞书”显著大于“效率先锋”，同时第二行不弱到失去识别度。
- 默认所有文字颜色为白色：`colorMode: custom` 且 `color: #ffffff`。自动取色仍保留为用户选项。

### 2.2 导出交互

- 底栏 / 面板底部的主“导出”按钮直接合成当前图并触发浏览器下载。
- 导出抽屉保留格式、体积、上限提示与复制链接；动作区固定为“下载”和“复制图片”两个按钮。
- 复制图片使用 Async Clipboard 的 `image/png`。不支持或无权限时给出失败提示，不静默降级成复制链接。
- 下载始终优先浏览器下载；微信内置浏览器仍保留长按保存预览兜底。
- 下载与复制共用同一套 `composeAvatar` 与编码管线，避免预览、下载、剪贴板三张图不一致。

### 2.3 行级排版

- `typography.lineSizeScales` 与 `typography.lineOffsetsX` 保存行级参数，均为数组，缺省 `[1, 0.62]` 与 `[0, 0]`。
- 字号比例范围 `0.2..2`，以基准字号乘数表示；水平补偿范围 `-0.25..0.25`，以画布宽度比例表示。
- 自动填满时以整块文字实际包络做二分；每行按自己的字号度量、落位与绘制，文字效果尺度也按行字号计算。
- 自动换行产生的续行沿用其源段落的行级参数；显式换行才是新的行级索引。
- 竖排暂不暴露行级字号与水平补偿；该模式以列为单位，语义与“每一行”不同，避免做出误导性控件。
- 旧 `status` 链接里的 `layout.scale` 继续生效；新行级字段优先，缺省时按旧字段迁移，保证链接不失效。

## 3. 验收

1. 默认配置归一化后为方形、白色文字、两行默认文案，第二行字号约 0.62 倍。
2. 点击主“导出”只触发一次下载，不打开导出抽屉；下载文件仍满足格式与体积目标。
3. 导出抽屉内“下载”和“复制图片”均可独立使用，复制成功后系统剪贴板含 PNG。
4. 纯文字多行模式下，每行可独立调整字号比例与水平补偿，导出结果与预览一致。
5. `npm run lint && npm run typecheck && npm test && npm run build && npm run e2e` 全绿。
