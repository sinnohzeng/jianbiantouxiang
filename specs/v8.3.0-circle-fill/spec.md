# 圆裁整体放大与默认字体

状态：已封存

用户已认可 v8.2.3 的布局、间距与主副行比例。本轮不重新设计，只将完成排版的整组内容等比放大，在实际字体量测与品牌完整边界允许范围内最多增加 16%。新默认安全边距 3%，基准排版仍以至少 6% 边距计算，避免减边距导致重新分配内部空间。显式更大安全边距继续生效；手动字号或位移不接管。字体切换造成的字形差异不冒称精确复现用户原图。

简体中文新默认：第一行 Noto Serif SC 700，第二行 Noto Sans SC 700；存档明确字体和 null 跟随值保持。其他语言保持现有主行默认与可用字形，副行对应当地无衬线字体。CLI/MCP 默认主行 serif、副行 sans，明确参数继续受支持。

证据：用户原图 612.jpg、613.jpg 与飞书圆裁截图 614.jpg，Library IDs 见当轮审计。检查同文字、不同 Logo、短长文字及 32/48/64 px 圆裁；实际字号重新量测，不以线性估计代替。测试门禁、SDD、默认样张和文档同步，直接 main 发布。

## 实到范围

基准构图完成后统一放大，真实字号逐候选重测；八组网页对照与十六张 MCP 输出已生成。主行宋体 700、副行黑体 700 作为简体中文新默认，旧明确字体与 null 跟随保留；CLI/MCP 增加 secondaryFont 和 fillScale。东黎示例增大约 6.8%，不是每例达到 16%。

843 单元测试、lint、format、typecheck、build、3 项服务边界和 7 组实际渲染通过；51 项网页 E2E 完成（完整运行 49 项通过，修正旧 UI 断言后另外 2 项分别复验通过）。最终 CI 与线上证据见交付记录。
