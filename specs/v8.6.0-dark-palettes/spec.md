# 冷启动导出设置、客户字标与深色配色

状态：已封存。日期：2026-11-07。

## 范围

保持已认可头像排版，修复首次打开右下角导出设置的卡顿/闪现与 HARMAY 黑稿不可见问题。新增 10 组深色渐变，并让底栏种子变换按钮准确描述实际效果。

## 验收

- 用真实浏览器记录冷启动首次打开与二次打开的时序和动画；首次打开有即时可见反馈，保留关闭、焦点与减少动效行为。不得以固定等待时间伪造动画，不修改生成的 UI 原语。
- 对 HARMAY 原始黑白稿核验可见 alpha、颜色、透明留白、预览与导出；区分黑底黑字的低对比和素材真正未渲染。不改变品牌比例、路径或擅自添加描边。
- 新增恰好 10 组深色配色，有五语名称、稳定 ID 和白字推荐；不修改现有配色或默认头像样式。基于一手研究及实际渲染选色，使用对比度作为工程约束而非美感评分。
- 新配色停靠点与实际背景样本分别测量：至少覆盖四种质感、多个种子及默认高光；默认参数的白字目标最低 4.5:1，强高光等非默认状态不虚称保证。完整图与 32/48/64 px 圆裁人工检查。
- 核查底栏种子按钮只改变哪些配置，以简洁文案和提示说明；五语同步，保留随机配色独立行为。
- 完成单元、类型、lint、格式、构建、桌面/手机 E2E 与截图检查；研究以 OKF v0.2 记录，经验与文档同步，经验证直接 main 提交推送并核查 CI/主站。
