# 实施计划

1. 三路只读研究与真实流程检查，记录已复现、静态确认和假说的区别。
2. 修复公共图形、后台任务、导出快照、持久化和字体刷新链；用受控异步与实际浏览器验证。
3. 预览点按和焦点避让、微信结果状态；不重新设计头像及增加无关编辑功能。
4. 更新一手研究、流程审计、当前文档及经验，检查没有重复或过时表述。
5. 单元、lint、格式、类型、构建、E2E、截图及服务测试；检查实际图片和控件位置后定版。
6. 封存规约，提交与标签推 main，追踪 CI/主站；报告文档、长期记忆及真实限制。

## 评审决定

无需数据库。现有纯前端配置和可选独立 MCP 服务边界保持。资源问题采用单在途和现有校验，不加入任务系统；图形白名单不因保留渐变而放宽外部访问。研究的触区标准与项目 44 px 目标分开，前沿论文不自动产生需求。
