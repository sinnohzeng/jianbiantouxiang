# 编辑流程与导出可靠性

状态：已封存。日期：2026-11-07。

## 用户任务与范围

保持已认可的头像排版与字体、比例；手机和桌面均能完成客户 Logo、两行文字、尺寸位置微调、撤销、恢复自动、导出。研究以原始论文和官方指南为依据，记录适用限制，不将偏好实验当效率证明。

## 验收

- 手机预览高度可点按调节及恢复，保留拖动和键盘；触区至少 44 CSS px。320 px 重排、sticky 区域不遮住编辑焦点。
- 微信体积选项按实际 JPG 计算；配置改变后不把旧结果当当前图显示。公共导出文件扩展名对应 Blob MIME。
- 异步导出记录开始时配置；页面隐藏或离开时同步待存档。上传字体替换后预览与导出一致。
- SVG 内部线性/径向渐变保留；脚本和外链仍剔除。手机保存图单在途，只保留最新待办。
- 审查上传竞态、资源限制、Web/CLI/MCP 边界；只实施代码证据支持的修复。
- 运行现有全部门禁、增补缺陷回归，实测 320/390/768/1024/1440/1920 视口与主要流程；模拟设备不冒充真机或辅助技术验收。
- 研究、架构、操作说明、经验及审计同步落盘；OKF 0.2 bundle 校验，遵循记忆准入。直接 main 发布并核验 CI 和主站。


## 实到范围

按正文实现并回归，详细证据见 `docs/audits/2026-11-07-editor-reliability.md` 与 CHANGELOG v8.5.0。补充了图形像素/会话容量边界、索引网络错误恢复，以及字体注册变化时旧导出结果失效。网页已认可的排版和默认值保持。

原生手机键盘、触屏辅助技术及真实微信/飞书客户端未验收；浏览器模拟与本地官方 SDK 测试的范围已在审计中标明。云环境沙箱启动受宿主配置限制，本地固定夹具使用既有测试模式，生产服务仍要求沙箱。全部实现、研究、经验与当前文档随同一版本入库。
