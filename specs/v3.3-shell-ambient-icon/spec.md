# v3.3 规约：关于、历史挪位、重置、环境光与 favicon 重做（造什么）

状态：已实现，2026-09-01。产品判断：主用户是“用完即走”的路人，所有者是最高频用户。
因此主屏不加一等控件，元信息与低频动作收进关于对话框；历史仍是“最近 8 条”但挪到
独立区域；环境光默认压制并允许用户调；favicon 重做为与品牌对得上的单一图形。

## 1. 目标

路人 30 秒会用：主屏控件数量不增加。回头客找得到：关于、重置、环境光各有固定入口。
品牌对得上：favicon、顶栏品牌块、PWA 图标共用一份矢量与渐变色值。

## 2. 用户故事

1. 路人打开站点，顶栏图标数量与过去相同，直接输入文字导出，不被新控件打扰。
2. 所有者点顶栏“关于”，一眼看到当前版本号，确认线上是哪一次部署。
3. 调乱了配置的人在关于对话框点“恢复默认设置”，画面回到首屏默认；反悔了用撤销退回。
4. 觉得浅色背景晃眼的人，在主题菜单把环境光滑杆调低；喜欢原样的人调回中位或更强。
5. 同一浏览器里先做“请假中 9 月 1 号到 7 号”，后改日期重做，最近生成条在列顶随时点回上一张。

## 3. 功能规约

### 3.1 favicon 与品牌标

- 图形为渐变圆角底加白色“渐”字，弃英文 G；16 像素下单一图形可认。
- `public/icon.svg`、`public/icon-maskable.svg`、顶栏 `BrandMark` 共用同一组渐变色值。
- maskable 版全幅铺满，图形收在 80% 安全区内。
- `npm run gen:app-icons` 从 SVG 位图化 `icon-192.png`、`icon-512.png`、`icon-maskable-512.png`。

### 3.2 关于对话框

- 顶栏原源码图标位改为“关于”按钮，图标数不变；源码链接移入对话框。
- 对话框展示：品牌标与名称、版本号、一句话简介、源码链接、许可说明、恢复默认设置按钮。
- 版本号由 vite define 注入 `__APP_VERSION__`，来源 package.json 的 version。

### 3.3 恢复默认设置

- 调 `store.reset()`，走 `commitConfig`，进撤销栈，可 undo 退回；不上确认弹窗。
- 恢复后 `LocaleDefaults` 按引用认出默认档，示例文字与默认字体重新跟随界面语言。
- 历史与本地存档不清：历史是存档不是设置。

### 3.4 历史挪位

- “最近生成”移到面板列顶部独立区域，带 `h2` 标题，空态一行字。
- 条数上限、缩略图、点击恢复等行为不变。

### 3.5 环境光

- 新增模块 `src/app/ambient.ts`：强度 0 到 1，默认 0.5，落 localStorage，不进 AvatarConfig。
- 浅色主题光晕颜色经 OKLCH 压制：饱和乘 0.55，明度减 0.06 并夹在 0.5 到 0.88。
- 不透明度以各主题基线（浅 0.45、深 0.28）乘强度比例，上限 0.9。
- 滑杆放主题菜单，深浅主题共用一个强度值。

## 4. 非目标

- 不做历史扩容、搜索与删除；不做多档背景预设。
- 不把环境光强度写进分享链接与存档。
- 不做埋点与使用统计。
- 不重置历史与本地存档。

## 5. 验收

1. 顶栏图标数与 v3.2 相同；关于对话框展示版本号，且与 package.json 一致。
2. 恢复默认后画面与首屏默认一致，示例文字跟随界面语言，undo 可退回。
3. 环境光滑杆调 0 后刷新，强度仍为 0；浅色默认光晕比 v3.2 明显更 subdued。
4. 历史条在面板列顶可见，桌面与手机均不被预览挤出首屏。
5. favicon 在 16 与 32 像素肉眼可认；maskable 图形在安全区内。
6. `npm run lint && npm run typecheck && npm run test && npm run build && npm run budget && npm run e2e` 全绿。
