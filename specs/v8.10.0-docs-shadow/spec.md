# v8.10.0 文档、分支与文字投影

状态：已封存。日期：2026-11-14。

## 读者与范围

新用户需要快速生成头像；开发者需要可运行的 CLI/MCP 示例；维护者需要清晰的验证和发布步骤。README 只提供入口，操作、接口和实现分别说明。正文定稿须结合用户提供的《怎样写作》阅读结果。

分支以最新 main cfd34ad（v8.9.0）为基线。所有分支先核对独有提交和补丁等价性，保存可恢复副本，再整合有效内容、清理到仅 main。保留旧提交证据，不覆盖远端的新工作。

头像两行文字默认使用强度 0.4 的投影，沿用现有绘制实现。首次进入、重置与自动化共享默认；存档缺字段补默认，显式 plain、其他效果及强度保留。投影不改变已认可图文排版，也不作用于网页界面或品牌图形。

## 实施前评审

用户体验：投影只辅助字形边缘，不能替代浅底文字的对比度；保留颜色和效果选择。排版：轻投影应与纯色共用自动放大，手动位置不改。持久化：旧存档无法区分旧默认与用户主动选择，所有显式值都保留。工程：复用现有 Canvas 绘制和共享配置；CLI/MCP 不另设默认。文档：先按任务分配内容，再改句子；历史规范与研究保留。分支：归档原提交后删除，独有配色移植到当前结构，不恢复过时默认。
