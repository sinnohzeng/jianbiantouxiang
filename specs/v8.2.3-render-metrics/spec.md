# 缩放后的真实字体边界

状态：已封存

v8.2.2 云端集成测试失败；用相同 Chromium 156 复现：256 px 样例的安全圆半径 112.64，光学微缩后报告矩形角点半径 112.93。关闭光学时为 112.58。原因是求解按旧字形边界线性缩放，但 Chromium 的字体墨迹量测会随字号离散变化。

修正要求：圆裁求解的每个缩放候选使用当前字号重新量测 TextMetrics；最终行宽/上下伸部与输出元数据一致。横向补偿同时约束可见采样和字体量测边界。不放宽原有圆裁断言、不取消光学功能、不改变本轮层级目标。以系统 Chromium 和 CI 同版 Chromium 实际回归，保留失败与修复证据。

## 实到范围

候选字号重测、最终边界同步及横向双重约束均已实现。同版 Chromium 原失败样例修复后回到安全圆内，两个浏览器的 7 组服务集成均通过；新增四档尺寸回归。最终网页 E2E、CI 与部署结果见交付记录。
