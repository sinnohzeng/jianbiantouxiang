# ISV 素材入库与 Logo 尺寸统一

状态：已封存。日期：2026-11-12。

## 需求

1. 用户从公开渠道收集的 ISV 品牌素材全部入库，单独成“ISV”分组。
2. 旧版豆包工作（蓝色环形图标及其黑、白组合）停用并删除，换成人物形象版。
3. 不同宽高比、不同像素尺寸、带或不带透明边的 Logo，在头像里要有统一的分量感。Logo 大小按什么口径算由 Claude 按最佳实践定。

## 现状证据

inbox 素材：`品牌logo透明底素材包` 11 个品牌、92 个透明底 PNG，像素尺寸从 65×268 到 3200×1596，全部紧贴裁切；`豆包工作品牌标识-11月` 3 个 PNG；`lark.svg` 与 v8.7.1 已退役的旧飞书图哈希相同。

全库 184 个素材在 Chromium 里按生产加载代码量测（数据与方法见 `docs/audits/2026-11-12-logo-size.md`）：

- 26 个素材自带超过 1% 的透明边，今日头条上下各 28%，字节跳动纯白上下各 34%，飞书与飞书组合上下各 15%。版面按文件画布排，这些 Logo 看起来明显偏小。
- 带文字时 Logo 等比放进“安全框全宽 × 52% 高”的参照框，宽高比 1.9 左右的 Logo 占到方形 Logo 的近两倍面积。分贝通、Moka、智慧芽图标与合思字标都落在这一段，比同组方形图标大一圈。
- 同一个标的品牌色版与纯黑、纯白版像素密度差很大：小裂变图标 0.99 对 0.72，合思图标 0.96 对 0.65，销售易图标 0.96 对 0.80。
- 全库出图暴露两个静默失效：Chrome 与 ChatGPT 缺色缺形。

## 设计

**大小口径。** Logo 大小一律相对画布的安全框计算，素材的像素尺寸只用来取宽高比。按原图像素的百分比缩放会让 65×268 的北森图标和 3200 宽的字标相差几十倍，不可用。归一分三步：

1. 裁边：品牌素材按可见像素的外接框排版，透明边由版式补回。东黎素材自带品牌规范要求的留白，原样保留。
2. 等面积：带文字时，宽 Logo 的高度取“与同档方形 Logo 等面积”，即参照高除以宽高比的平方根；高度封顶在参照高，宽度封顶在安全框宽。方形、竖长与宽高比 3.7 以上的 Logo 落在封顶上，与原规则相同；只有 1 到 3.7 之间的 Logo 收小。
3. 滑杆：百分比在上述基准上线性缩放，区间与 v8.8.0 相同，全程无死区。纯 Logo 时仍取圆形安全区内最大同比例矩形，它已经是圆内最接近等面积的尺寸。

否决：

- 密度补偿（LogoSoup 默认开启）：同一个标换颜色就会大小不一，差 8% 到 9%。
- 竖长 Logo 放宽高度上限：北森图标、Figma 会更有分量，但文字可用高度减少约四分之一，文字是头像的主体。
- v8.8.0 否决过不封顶的面积归一，理由是改动所有非正方形 Logo 的默认大小，超宽 Logo 还会压小文字。本方案加了两道封顶，只改动 1 到 3.7 这一段，那一段正是用户看出“不统一”的来源。

**ISV 分组。** 分类 `isv` 紧跟字节跳动分组，五语标签都写“ISV”。条目 ID 为 `isv-<品牌>-<symbol|lockup|wordmark>-<color|black|white>`，中文名按源文件名写“品牌 · 图标 · 品牌色”，品牌按拼音排序。全部按精确原稿使用：保留原色，不给单色档，选择器缩略图垫白底，纯白版垫深底。

**豆包工作。** 稳定 ID `doubao-work`、`bd-doubao-work-black`、`bd-doubao-work-white` 不变，分别指向新资源 `doubao-work-avatar`、`bd-doubao-work-avatar-black`、`bd-doubao-work-avatar-white`；组合名改为“黑字组合”“白字组合”。旧文件从 `assets/brand/` 与 `public/brand/` 删除，旧存档按 ID 自动换成新图。

**附带修复。**

- `sanitizeSvg` 遇到百分比宽高时同样按 viewBox 补固有尺寸。裁边后微博的 SVG（宽高写 `100%`）只画出一角，上传路径一向裁边绘制，有同样的问题。
- 生成期把引用内部自闭合元素的 `<use>` 展开成 `<g>`，修复 Chrome 与 ChatGPT。运行时净化器的白名单不变。
- ISV 素材近 19 MB，不进 PWA 预缓存，用到哪张缓存哪张。
- 历史缩略图版本升到 2：品牌与上传图形的旧缩略图失效，配置保留。
- 东黎客户预设按新规则换算，可见尺寸与原样张一致：图形标 0.49 → 0.63，完整组合 0.52 → 0.6。

## 验收

- 量测脚本：184 个素材全部加载并画出可见像素；居中、Logo 滑杆单调、行高单调三组不变量全部满足。
- 新旧规则真实合成对照，覆盖 ISV 三种形态、纯 Logo、字节与常用品牌、客户预设。
- 每处修复有回归单测，撤回修复后失败。
- `npm run ci` 全绿，截图逐张看过。

## 实到范围

按正文实现，证据见 `docs/audits/2026-11-12-logo-size.md` 与 CHANGELOG 8.9.0。v8.8.0 记录的边界“飞书 Logo 在 65% 以上整组偏 2–2.5%”因裁边消失，大尺寸下偏差不超过 0.05%。豆包工作黑、白字组合宽高比 3.63，落在等面积段的边缘，比旧规则小约 1%。CLI/MCP 的 `logoScale` 未改。
