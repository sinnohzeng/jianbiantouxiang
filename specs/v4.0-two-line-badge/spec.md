# 两行徽章模型 v4.0 规约（造什么）

状态：待评审，2026-09-01。把 v3 的三个用途（纯文字 / 状态徽章 / 图标徽章）收敛为一个两行模型，
并承接同轮四项决定：默认投影、预设常见文字色、行级水平补偿解耦、导出文件名加时间戳。

## 1. 目标

用户不再挑选「用途」。图标（可选）、第一行、第二行三个原料填进去，
引擎用一个纵向栈把所有组合排出来，自动缩放适配安全框。
头像最多两行文字，版式由系统定，预览与导出一致，旧链接迁移后可用。

## 2. 用户故事

1. 只填「暴富」，第二行空：一行大字居中，字号自动放大。
2. 填「飞书」「效率先锋」：大行在上，小行在下，比例默认 0.62。
3. 开图标并填两行：图标在上，第一、二行按比例缩小，整栈落在安全框内。
4. 开图标，第一行空，第二行填「效率先锋」：图标加说明文字，第二行晋升主行。
5. 选黑色文字配投影：阴影自动换白漫射，深色字从深背景里托出来。
6. 拖第一行的水平补偿：只有第一行动，第二行纹丝不动。
7. 连续导出两次：文件名带秒级时间戳，互不覆盖。
8. 打开旧的三行链接或任意旧用途链接：迁移后正常显示，不报错不出空白。

## 3. 功能规约

### 3.1 契约

- `v` 从 3 升到 4；`text` 字段形状不变（`\n` 分隔），解释收敛为最多两行，第三行起并入第二行。
- `layout.kind` 退役：字段保留以解析旧存档与旧链接，渲染不再按它分派；界面移除用途选择。
- `typography.lineSizeScales` 与 `lineOffsetsX` 截到两档，语义不变：次行字号比例、逐行水平补偿。
- 默认值变更：`effect` 取 `shadow`，`effectStrength` 取 0.4，`colorMode` custom、`color` 白。
- 迁移集中在 `normalizeConfig`：v3 输入按 §3.6 映射；URL 解码与本地存档共用这一入口。

### 3.2 排版（栈模型）

- 渲染栈自顶向下：图标（若设置）→ 第一行（若非空）→ 第二行（若非空），水平一律居中。
- 第一行为基准字号；第二行 = 基准 × `lineSizeScales[1]`（默认 0.62，可滑 0.2 到 0.8）。
- 第二行为空：只渲染第一行，自动填满放大字号。这是「默认按第一行内容走」的确切含义。
- 第一行为空、第二行非空：第二行晋升基准字号。任何输入组合不吞内容。
- 图标占栈顶，高度 = 安全框高 × `layout.graphic`（0.3 到 0.8）；
  文字块用剩余高度，求解器二分搜基准字号，使整栈不越安全框。
  图标在时第一、二行随栈整体缩小，即「合理地缩小之后整体展示出来」。
- 水平补偿逐行独立：改第 i 行只动第 i 行。补偿参与包围盒计算（自动填满预留余量），
  但不做跨行再分配。验收判据：任何配置下只改 `lineOffsetsX[i]`，
  其余行的像素位置不变，第 i 行位移等于补偿差乘画布宽。
- 单行内容过长时仍可在行内自动换行兜底（沿状态徽章现行策略：能不折就不折）；
  显式多行不再存在：粘贴进来的换行在输入时合并为一行。
- 行距沿用 `lineHeight`，作用于栈内相邻块之间。
- 随纯文字用途一并退役：竖排、九宫格锚点、对齐、全局偏移、自动换行开关。

### 3.3 效果与文字色

- 默认效果投影、强度 0.4，替换现行默认光晕 0.5。
- 投影颜色跟随文字色反色适配：浅色字用黑阴影（透明度随强度升），深色字用白漫射阴影。
  与描边、光晕、底板同一套反色口径；「黑字黑阴影不可见」的空洞由此补上。
- 自定义文字色增加预设色板：白 `#FFFFFF`、黑 `#141413`、米白 `#F5F1E8`、明黄 `#FFD34D`，
  保留自选色。预设色与投影适配逐一可验。
- 自动取色行为不变：内置配色用设计值，custom 配色走像素判定，对比度不足补底板。

### 3.4 导出命名

- 文件名格式：`<文字>_<宽>x<高>_<YYYYMMDD-HHmmss>.<扩展名>`，时间戳取设备本地时区，精确到秒。
- 清洗规则不变：先删非法字符与空白，再截 12 字符，清空回落 avatar；时间戳不参与清洗与截断。
- 同秒内连续导出仍可能重名，接受这一边界：导出本身耗时超一秒，加毫秒得不偿失。
- 同步更新 spec §3.5 的命名条款与 `tests/export/filename.test.ts` 全部锁死用例。

### 3.5 界面

- 文字面板基础组：移除用途分段控件；第一行、第二行两个单行输入；
  图标开关与图形选择器常驻本组，图标可选、可换、可清。
- 常驻操作条：「随机颜色」（只换种子）与「随机全部」（质感＋配色＋种子）提为两个一级按钮，
  取消下拉二级；新增「文字」快捷入口，点一下切到文字页签并聚焦第一行输入框；
  窄屏（约 360px 以下）整条按钮退化为纯图标态。复制链接与导出不动。
- 排版组保留：字体、字重、字号模式、行距、字距、第二行字号比例、逐行水平补偿。

### 3.6 迁移与兼容

- 旧链接与存档（`v:3`）由 `normalizeConfig` 迁移：
  `kind:text` 第一行保留、其余行并入第二行；`kind:status` 一一映射；
  `kind:logo` 保留图标与图形比例，文字按同一规则收成两行。
- 行级数组一律截到两档，超出档位丢弃。
- 上传图形仍只存会话、不进分享链接，沿用 v3.2 口径。

## 4. 边界（不做）

- 三行及以上：不支持，不预留扩展位。
- 图标与文字左右并排：不支持，栈只有纵向一种。
- 逐行垂直补偿：不支持，水平补偿已覆盖现有诉求。
- 「第二行复用第一行内容」的重复美学：不做成默认行为，用户手打两遍同样内容即可得到。

## 5. 验证

- 单测：栈求解器五种组合（仅一行 / 两行 / 图标＋一行 / 图标＋两行 / 仅图标）、
  第二行晋升、补偿独立性回归（先红后绿）、迁移用例（三行链接与三种旧用途各一）。
- e2e：旧链接兼容、常驻按钮行为、导出文件名带时间戳。
