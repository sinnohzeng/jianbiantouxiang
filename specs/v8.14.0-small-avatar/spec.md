# 小头像效果检查

状态：已封存。基线 v8.13.2 / 69c6d1a。

用按需小尺寸效果检查替代常驻小字劝删提示，不修改默认配置、排版算法、手动字号、字体或服务契约。沿用当前导出管线与编码参数，在弹层中按中心圆裁显示 32/48/64 CSS px，默认选中 48；明确为模拟而非聊天客户端实测。根据所选尺寸筛查主副行墨迹高度，6px 只作轻量风险筛查，无提示不代表可读性认证。

只在检查中说明风险。保留原预览越界警告，检查窗口内也保留原布局的越界诊断；中心裁切效果由小图实际展示。提供定位已有第二行字号控件和隐藏第二行操作，隐藏沿用配置撤销，不清空字体、字号等设置。只剩第二行时不隐藏唯一文字。加载时不显示旧配置图；失败可重试；关闭停止待办并丢弃在途旧结果；字体更新后重新生成。

复用现有 Button/Dialog 与串行去抖调度，不引入新组件库。触控目标 44px、弹层可滚动，桌面和窄手机不溢出。完整 CI、五语字典、真实导出同源像素、尺寸/撤销/定位/重试/配置变更验证及截图；main 和注解标签发布，核对生产。
