# 第一行默认黑体最重字重

状态：已封存。基线 89e3c35 / v8.13.1。

用户仅修改网页第一行默认字体：Noto Sans SC 900；第二行仍为 Noto Sans SC 700。其他默认配置、自动排版算法和显式存档不变。首次、缺失字段和重置使用新默认；不按旧值猜测迁移用户选择。

安装的 @fontsource/noto-sans-sc 5.3.1 元数据支持 100–900，含独立 900 CSS/WOFF2；为 900 增加本站按需加载，保留 Sans 700 与 Serif 600/700。必须验证真实字重文件及网络响应，禁止只凭 CSS 声明推断。

CLI/MCP v1 独立默认 serif / sans、固定 700；本次保留，不扩展接口。共享的绘制与配置归一化仍按既有调用约定工作。

验收：完整 CI，默认/重置/显式旧值、同家族不同字重；新浏览器封锁外部字体网络，首次与导出真实加载本站中文 900 和 700 分片；真实渲染与 24/32/40/48/64 px 圆裁、标准样张与界面截图；直接 main＋注解标签发布并核验线上。

## 实到范围
