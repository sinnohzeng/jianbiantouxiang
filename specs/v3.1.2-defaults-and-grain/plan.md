# v3.1.2 实施计划

对应规约：`spec.md`。按薄切片推进，每一步都能独立验证。

状态：已落地，2026-08-31。

## 1. 契约与默认值

1. 修改 `DEFAULT_CONFIG.typography.padding` 与 `lineHeight`。
2. 补单测：默认值、归一化、旧链接显式字段仍生效。
3. 不改 `AvatarConfig` 字段语义。

## 2. 交互顺序

1. `StylePanel` 把种子区移动到质感选择之前，不改控件本身。
2. `TextPanel` 把逐行字号控件移动到全局字号之前。
3. 给 `SliderField` 增加常驻数值输入能力，逐行字号使用它；标签带上行号与该行文字，方便区分正在改哪一行。

## 3. 颗粒质感

1. `GRAIN_SHAPE_POOL` 删除 ripple。
2. 更新形状池单测与缩放倍率断言。
3. 保留 wave 与 corners，两种形状仍共享 0.45 的缩放倍率。

## 4. 验证与文档

1. 单测覆盖默认值、形状池、行级字号输入。
2. e2e 维持方形默认、直接下载与多行文字链路。
3. 截图核对桌面与手机两档。
4. 更新 README、架构、CHANGELOG、工程经验与项目记忆。

## 5. 提交切分

1. 规约与计划。
2. 默认值与测试。
3. 面板顺序与行级字号输入。
4. 颗粒形状池。
5. 文档与记忆。

## 6. 计划评审后的补充

- 默认值变化会影响省略这些字段的旧分享链接；不改编码规则，只在文档里写明“缺字段取当前默认值”，并用显式旧值的单测守住不受影响。
- 逐行字号不改成像素，仍用比例，保证同一配置在 512、1024、2048 下等比。
- 常驻数值输入只给逐行字号，不给所有滑杆，避免为了一个诉求改全局交互。
- 颗粒只删 ripple，不重写 shader；这是对观感的最小修正。
- 不新增数据库或迁移，本轮仍只涉及前端配置与渲染。

## 7. 验证结果

- `npm run lint`、`npm run typecheck`、`npm test`、`npm run build`、`npm run e2e` 全绿。
- `npm run screenshots` 生成 16 张设备截图，覆盖桌面、iPhone 15 与 iPhone SE 的深浅主题。

## 评审修订（2026-08-31）

- 审计实测首屏 JS 为 204.09 KB gzip（index 154.16、preload-helper 11.05、i18n 16.70、
  useScrollLock 22.18），在 250 KB 预算内；v3.1 规约里 160 KB 的旧目标作废。
- v3 线缺发布标签、README 样张停在 v3.0 调参期（颗粒列带已移除的同心圆），
  两件与其余审计发现一起落在 `specs/v3.1.3-debt-and-hygiene/`。
