# v3.1.2 默认值、种子位置与颗粒调整规约

状态：已落地，2026-08-31。本轮只改产品口径，不引入新数据结构。

## 1. 目标

1. 默认画布保持方形，不新增圆角默认值。
2. 默认文字边距改为每边 15%，默认行高改为 1.03。
3. 质感面板中，种子输入、种子哈希、复制与换种子按钮整体移动到质感选择之前。
4. 颗粒质感的形状池去掉 ripple，保留 wave 与 corners，避免随机种子频繁出现同心圆。
5. 两行及多行纯文字状态下，逐行字号控件移动到全局字号之前，并且数值输入常驻可见，不再只靠点数值按钮进入编辑态。
6. 导出主按钮默认触发下载，本轮不改。

## 2. 非目标

- 不改变导出管线与剪贴板行为。
- 不把行级字号从比例改成像素，比例仍是唯一契约。
- 不新增逐行字号的快捷预设，也不做自由排版。
- 不为默认值变化做数据迁移，分享链接仍按“缺字段取当前默认值”的既有规则解释。

## 3. 验收

1. `DEFAULT_CONFIG.typography.padding` 为 0.15，`lineHeight` 为 1.03，画布 `shape` 仍为 `square`。
2. 质感面板的种子区在质感选择区之前，换种子按钮仍是 44 px 触控目标。
3. 颗粒质感的 `u_shape` 只会落在 wave 与 corners，不会再取 ripple。
4. 纯文字多行状态下，每一行字号控件位于全局字号之前，数值输入可以直接敲入百分比并写回 `lineSizeScales`。
5. `npm run lint`、`npm run typecheck`、`npm test`、`npm run build`、`npm run e2e` 全绿。
6. README、架构文档、CHANGELOG、工程经验与项目记忆同步更新。

## 4. 落地记录

- 默认值、面板顺序、行级字号输入与颗粒形状池均已实现。
- 单测覆盖 627 个用例，`npm run e2e` 12 条通过，生产构建通过。
- 旧分享链接里显式写出的 `padding` 与 `lineHeight` 仍按原值渲染；省略这两个字段的链接按新默认值渲染。
