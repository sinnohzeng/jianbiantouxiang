# 飞书真实截图对照后的双行修正

状态：已封存。

用户提供 HARMAY、东黎羊绒和飞书原生“北区 / 连接器”截图。8.1.0 增大图文栈，但无 Logo 双行仍将第二行固定为首行 62%，使同等重要的团队标识失衡。

- 无 Logo、第一行自动且第二行跟随时，两行以相同字号共同适配圆形安全区；不根据语言或猜测语义分支。
- 有 Logo 的主标题/副标题保留既有 62% 层级；明确手动字号仍按原值处理。
- 网页滑杆显示与切换手动值使用同一规则；CLI/MCP 的纯文字双行同样使用共同字号。
- 用用户截图近似提取 Logo 做重建对照，明确区别原始截图、重建生成与实际客户端验证。
- 实际运行 CLI 和官方 SDK MCP 出图；验证圆裁、可见占比、整体中心和 24/32/48/64 px。

## 执行与验收

先修复共享字号规则和对应测试，再跑完整工程门禁及浏览器回归；量化和视觉验证后按功能分支、PR、CI、合并与标签流程交付。保持现有部署设置，禁止清缓存或重复触发旧部署。远程 MCP 不发布。

## 真实 Logo 导入补充

官网备用字标 SVG `/media/harmay-logo.svg` 由导航组件直接引用，另有当前首页 PNG。素材只在独立测试目录使用，不随公开源码分发。用真实文件发现并修复：网页上传按透明像素裁边后排版，保留原图源矩形；简单 SVG 类绘制样式安全转属性；PNG 压缩元数据在解码前剥离而不解压。通用回归使用自造图形，新增 `scripts/review-logo.mjs` 接受调用者提供的素材。
