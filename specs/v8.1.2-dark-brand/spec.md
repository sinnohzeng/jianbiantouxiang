# 深底品牌头像默认体验

状态：已封存

本轮使用客户提供的透明黑白 PNG 与 SVG 作为独立测试输入，不把商标素材加入公共仓库。默认采用钢灰深色渐变、白色文字、低光感和无投影；已有显式配色与效果保留。保持原始字标比例，不拉伸、描粗或重绘。自动图文模式副行提高至主行的 80%，手动主行继续采用既有 62% 跟随；纯文字自动双行仍等大。边距继续 6%，逐元素圆裁校验及整栈居中不变。

验收：客户白色 PNG 与 SVG、无 Logo、Logo 一行/两行，32/48/64 px 真尺寸圆裁；对比旧版副行墨迹高度，主行宽度不低于圆径 70%，副行可读性提高；测量背景下文字对比度且不把抽样值声称为 WCAG 合规。四种风格、黑白输入、现有手动样式和安全边界继续可用。完成仓库门禁、真实 MCP/CLI 与网页导出验证。

实施顺序：核查研究与原始素材 → 生成基线 → 修改共享默认与自动副行比例 → 生成候选并检查真实小尺寸 → 回归、定版、按用户最新授权直接推 main → 核实 CI 与主站。
