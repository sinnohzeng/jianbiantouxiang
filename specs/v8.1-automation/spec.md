# CLI 与远程 MCP 首版

状态：已封存。用户授权先实现与验证，部署使用已授权目标；不得新建凭据或扩大访问权限。

## 范围

- 同仓库提供 Node 24 CLI、批量 JSON 清单、stdio 与 Streamable HTTP MCP。
- 独立自动化渲染页面复用网页 shader、颜色和编码，不依赖线上网页或 UI/localStorage。
- 输入为版本化、严格校验的两行文字、PNG/SVG Logo、配色、质感、种子、方形尺寸。
- 自动化默认 1024 px，14% 安全边距，Logo 裁透明边/识别黑白底后等比缩放，默认跟随配色文字色；文字最多两行，不自动换行。
- 自动化排版独立成配置档，网页默认值和交互保持不变。输出安全区、各元素边界、字号、渲染告警。
- 字体随构建打包，渲染不访问互联网。每次请求隔离浏览器上下文。
- 上限：图像 2048 px、输入 Logo 512 KiB/4096 边长/1600 万像素、SVG 2000 节点/32 层、每批 8 张、进程串行渲染且队列有界、单张超时。
- HTTP 无会话、无远程文件路径/URL、无持久上传或公开文件下载。默认只绑定 loopback；非 loopback 必须配置 Bearer token 或显式匿名公开模式（部署需网关限流）。Host/Origin 校验、请求大小与进程级速率限制。
- MCP 返回图片及结构化验证结果；CLI 原子创建输出文件，默认拒绝覆盖。

## 非目标

不替换现有 ESA Pages；不为静态边缘站强行启动 Chromium。不承诺所有客户端均支持同一种远程认证；首版提供 stdio/HTTP 配置并说明 OAuth-only 客户端限制。不自动发布 npm 或公开匿名服务。

## 验收

现有五项门禁；新参数、图片消毒、裁边、布局、安全边界、CLI/HTTP MCP 集成测试；实际 PNG/SVG、黑/白/横宽/纵长 Logo、多语言两行、纯文字和纯 Logo 出图与接触表视觉检查。

## 实到范围

对应 CHANGELOG 8.1.0。CLI/MCP 与自动化默认档完成；未改变网页默认参数或存档。实际增加了最终底图对比度抽样选色、字体缺字检查和原子文件输出。SVG 为有界轮廓子集，PNG 拒绝动画及压缩元数据；随包仅提供 Noto Sans SC 700。官方 SDK 1.32.2 的 HTTP/stdio 与 2025-11-25 协商已验证，未承诺所有桌面客户端或 OAuth-only 客户端直连。
