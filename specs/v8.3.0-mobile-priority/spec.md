# 手机高频调整优先

状态：已封存

承接圆裁整体放大；不修改已认可的头像风格。先核查真实手机视口和操作路径。文字输入、逐行大小与上下位置常显，字体、样式及低频版面设置折叠；Logo 的大小和上下位置常显，左右位置保持折叠。继续沿用同一组件树、已有滑杆与 sticky 预览，不增加另一个编辑模式。

提供一键恢复自动排版，仅恢复自动字号、图文位置与对应 Logo 默认比例，保留文字、字体、配色及已选 Logo。旧配置读取不变；手调并非自动布局已完美的证据，要继续暴露真实边界与溢出提示。
