# 图标徽章 v3.2 规约（造什么）

状态：已实现，2026-08-31。承接 `specs/v3.1-badge-templates/spec.md` 中标为 v3.2 的设计，并吸收 `docs/audits/2026-08-31-tech-doc-debt-audit.md` 对本规约的修订。

## 1. 目标

把“图形在上、文字在下”的图标徽章做完。用户能用内置图标、emoji 或上传图形做部门标识，预览与导出一致，分享链接在别的设备上还能复现内置图形与 emoji。

## 2. 用户故事

1. 做部门标识，选“图标徽章”，搜“棕榈”，用 🌴 或 lucide 的棕榈图形，下面填“产品设计部”，导出 1024 PNG。
2. 选内置图标，颜色跟随文字色，深浅配色下都看得清。
3. 上传自家产品 logo，SVG 里的脚本被剥掉，画布只留下绘图元素；上传只在本次会话有效。
4. 图形比例拖到 0.3 到 0.8 之间，文字仍在安全框内，不与图形重叠。
5. 把链接发给同事，内置图标与 emoji 复现；上传图形退回为空，对方可以自己上传。

## 3. 功能规约

### 3.1 契约

- `layout.kind` 增加 `logo`。
- `layout.scale` 在本版移除：v3.1.3 已标 deprecated，旧链接的迁移留在 `normalizeConfig`，契约里不再保留死字段。
- `layout.graphic` 表示图形占安全框高度的比例，范围 0.3 到 0.8，默认 0.52。
- `layout.icon` 记录来源与标识：`source` 取 `none`、`builtin`、`emoji`、`upload`；`id` 分别为空、lucide 名、去掉 `FE0F` 的码点串、本次会话 id。
- 旧链接缺这些字段时落到纯文字；v3.1 链接不失效。
- `encodeConfigToHash` 不写 `upload` 图形，来源退回 `none`。

### 3.2 排版

- 图形放安全框上部，文字放下部，间距为安全框高度的 0.06。
- 图形先按高度 `safeHeight × graphic` 等比缩放，宽度超出安全框时改按宽度约束，不拉伸。
- 文字在剩余高度内自动填满，水平居中；无锚点、对齐、竖排与自动换行控件。
- 文字为空时图形居中，占安全框较短边乘 `graphic`。
- 图形为空时文字按纯文字版式的居中口径排版，界面仍提示先选图形。
- 内置图形的颜色跟随文字色；emoji 与上传图形保留原色。
- 内置图形与文字共用当前文字效果与强度，emoji 与上传图形不做描边、投影或发光。

### 3.3 图形来源

- 内置图标来自 lucide-react 1.37 的 1790 个主图标。精选约 160 个带中英文关键词与类目；全库按英文名搜索。
- emoji 索引来自 emojibase-data 15.0.0，取 1879 个有官方分组的条目，五种界面语言各自生成名称与标签。
- emoji 图形按码点取 Noto Emoji v2.047 的单个 SVG；文件名用小写十六进制加下划线，去掉 `FE0F`。
- 上传支持 SVG、PNG、WebP。SVG 用元素与属性白名单重建，拒绝外部引用、脚本、事件属性与 `foreignObject`。
- 图形加载失败时图形位留空，渐变、文字与导出继续可用。

### 3.4 界面

- 用途分段控件增加“图标徽章”。
- 图标徽章下出现图形选择区：缩略图、换图按钮、比例滑杆。
- 图形选择器在桌面用命令对话框，手机用底部抽屉；内置图标与 emoji 分栏搜索，上传动作在底部。
- 选择器、图标索引、emoji 索引都懒加载；没有选择图形时不拉这些 chunk。

## 4. 非目标

- 不做图层、拖拽、多图形或自由摆位。
- 不内置具体产品 logo。
- 不把上传图形写进分享链接、localStorage 或历史。
- 不做批量上传与图形编辑。

## 5. 验收

1. 内置图标徽章可以搜索、选中、导出；深浅配色下图形颜色跟随文字色。
2. emoji 中文搜“棕榈”能选中 🌴，导出与预览同一张 SVG 图形。
3. 上传含脚本、事件属性与外部引用的 SVG 后，危险内容被剥掉，安全绘图内容保留。
4. 首屏 JS（entry 加全部 modulepreload 的 gzip 和）不超过 250 KB，由 `scripts/check-budget.mjs` 守；
   图形与 emoji 索引、选择器不在首屏 chunk。2026-08-31 评审修订：160 KB 旧目标作废，见 `specs/v3.1.3-debt-and-hygiene/`。
5. `npm run lint && npm run typecheck && npm test && npm run build && npm run e2e` 全绿。实测首屏 JS 200.22 KB gzip，低于 250 KB 上限。
6. 桌面与手机截图无横向滚动，图形与文字排版正确。
